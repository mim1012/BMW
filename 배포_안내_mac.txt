BMW AutoBuyer macOS 배포 안내

실행 파일:
- dist/BMW-AutoBuyer.app

빌드 준비:
- macOS 10.15 이상
- Python 3.8 이상
- Google Chrome 설치 필요

빌드 방법:
1. Mac에서 이 프로젝트 폴더를 엽니다.
2. 터미널에서 프로젝트 폴더로 이동합니다.
3. 최초 1회 권한 부여:
   chmod +x build_mac.sh
4. 빌드 실행:
   ./build_mac.sh

Apple Silicon / Intel 지정 빌드:
- 기본값: 현재 Mac/Python 환경에 맞춰 빌드
- Apple Silicon 전용:
  PYINSTALLER_TARGET_ARCH=arm64 ./build_mac.sh
- Intel Mac 전용:
  PYINSTALLER_TARGET_ARCH=x86_64 ./build_mac.sh
- universal2:
  PYINSTALLER_TARGET_ARCH=universal2 ./build_mac.sh

GitHub Actions에서 빌드:
1. Windows에서 코드를 GitHub 저장소에 올립니다.
2. GitHub 저장소에서 Actions 탭을 엽니다.
3. "Build macOS App" 워크플로를 선택합니다.
4. "Run workflow"를 눌러 실행합니다.
5. 완료 후 Artifacts에서 "BMW-AutoBuyer-macOS"를 내려받습니다.
6. ZIP을 풀면 BMW-AutoBuyer.app이 들어 있습니다.

사용 순서:
1. dist/BMW-AutoBuyer.app 실행
2. Chrome 열기 클릭
3. 열린 Chrome에서 직접 BMW 로그인 완료
4. 전체 스캔이 필요하면 전체 스캔 클릭
5. 차종/옵션/고정 딜러위치 입력 후 설정 저장
6. 구매하기 클릭
7. QR 화면까지 자동 진행됨
8. QR 이후 본인인증 및 후속 작업은 사용자가 브라우저에서 수동 처리

생성되는 파일/폴더:
- ~/Library/Application Support/BMW-AutoBuyer/chrome_profile
- ~/Library/Application Support/BMW-AutoBuyer/screenshots
- ~/Library/Application Support/BMW-AutoBuyer/user_config*.json
- ~/Library/Application Support/BMW-AutoBuyer/scanned_models.json, form_fields*.json

주의:
- Windows용 BMW-AutoBuyer.exe는 macOS에서 실행되지 않습니다.
- PyInstaller는 기본적으로 크로스 컴파일러가 아니므로 macOS용 .app은 Mac에서 빌드해야 합니다.
- 인터넷으로 배포하면 Gatekeeper 경고가 나올 수 있습니다. 정식 외부 배포는 Apple 개발자 인증서로 코드 서명 및 공증이 필요합니다.
- QR 화면 이후에는 자동 제출하지 않습니다.
